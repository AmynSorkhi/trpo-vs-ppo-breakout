# Blackout

## Installation

To set up the environment, run the following command in the terminal:

`pip install gymnasium[atari] ale-py`

## Blackout Environment

This folder involves the Blackout environment. We can experiment with our own policy update methods on this environment.


This script initializes and runs the Blackout environment (Breakout-v5). It displays the observation space, action space, and renders the game while executing random actions.
